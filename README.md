# Go Start — Go с нуля до среднего уровня

**Часть 1 из 2.** Продолжение — [Go Pro](https://github.com/meeymirita/go-pro-lab) (от middle до senior).

Лабораторная для Laravel/PHP-разработчика, который никогда не писал на Go. 12 сессий, около 50 часов. Сквозной проект **CoffeeGo**: CLI → REST API на `net/http` + PostgreSQL → Docker и CI. Темы: типы и срезы, ошибки как значения, структуры и интерфейсы, пакеты и модули, дженерики, тесты, горутины и каналы, HTTP-сервер, `database/sql`/`pgx`, конфигурация, Docker.

**Статус: ⚪ задание на генерацию методички написано (`brief.md`), сама методичка и код проекта ещё не созданы и не проверены запуском.**

| Файл | Что |
|---|---|
| `brief.md` | задание для генерации методички: читатель, формат, план по сессиям, приёмка |
| `go-start.html` | методичка (появится после генерации) |
