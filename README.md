# Go Start — Go с нуля до среднего уровня

**Часть 1 из 2.** Продолжение — [Go Pro](https://github.com/meeymirita/go-pro-lab) (от middle до senior).

Лабораторная для Laravel/PHP-разработчика, который никогда не писал на Go. 12 сессий, около 55 часов. Сквозной проект **CoffeeGo**: CLI → REST API на `net/http` + PostgreSQL 18 → Docker и CI. Темы: типы и срезы, ошибки как значения, структуры и интерфейсы, пакеты и модули, дженерики, тесты, горутины и каналы, HTTP-сервер, `database/sql`/`pgx`, конфигурация, Docker.

**Статус: 🟡 методичка написана (все 12 сессий, 69 шагов), запуском проверены только сессии 1–3** (Go 1.24.13, linux/amd64). Сессии 4–12 не компилировались; на macOS и на актуальной версии Go не запускалось ничего. Код прохождения — свой, эталонного кода в репозитории нет. **Не вычитана построчно. Вычитка (построчно, как у остальных лаб) и полный прогон кода запуском — впереди.**
